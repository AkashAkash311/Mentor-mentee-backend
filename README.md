# Mentor-Mentee Backend 🧠🚀

This is the **Node.js + TypeScript** backend for the **Mentor-Mentee Platform**, designed to handle user registration, mentor/mentee tagging, secure communication, payments, and more.

---

## 🛠 Tech Stack

- **Node.js** + **TypeScript**
- **Express.js**
- **MongoDB** + **Mongoose**
- **JWT** Auth (Bearer Token)
- **ESLint** for code linting
- **Prettier** for formatting
- **Husky** + **Lint-Staged** for pre-commit hooks
- **Yarn** as package manager

---

## 📦 Setup

### 1. Clone the repo

```bash
git clone https://github.com/your-username/mentor-mentee-backend.git

```


## 2. Install dependencies
```bash
yarn
```


## 3. Configure environment
```bash
PORT=3000
MONGO_URI=mongodb://localhost:27017/mentor-mentee
JWT_SECRET=your_jwt_secret
```


## 4. Start development server
```bash
yarn dev
```
